# JointSense v2 — 项目结构需求梳理（复盘文档）

> 生成日期：2026-08-07
> 用途：沉淀 JointSense 安卓端（ELISA 炎症因子检测 + OA 炎症指数）的整体结构、需求与关键设计决策，便于后续复盘与接手。

---

## 1. 项目定位与目标

**JointSense** 是一款面向骨关节炎（OA）患者的安卓应用：用户拍摄 ELISA 检测板照片，App 自动识别三个炎症因子的孔内色度信号，反算 `pg/mL` 浓度，并合成一个 **OA 炎症指数（AI，0~4 级）** 用于病情活动度评估与趋势追踪。

核心目标（需求来源）：
- 三个炎症因子定量：**TNF-α、IL-6、IL-1β**，单位统一 `pg/mL`。
- 从 ELISA 板照片（非酶标仪 OD）估算浓度 → 这是本项目的核心约束，决定了"色度代理"而非"OD 4PL"的技术路线。
- 内置一批已量化的检测数据，首次启动即有内容（不空屏）。
- 提供**引导式校准**：用户可用试剂盒标准梯度假板重新拟合曲线。
- 提供历史、趋势、报告、个人中心等完整工作台。

## 4. 运行时数据、迁移与导航

- Room v1 包含 `test_session`、`test_result`（`sessionId` 外键级联、非空 `draftId` 唯一索引）、`calibration`、`calibration_knot`（复合主键/级联）及 `app_metadata`。
- `LegacyMigrationCoordinator` 先完整解析旧 JSON，再在单一 Room 事务导入。旧结果迁移为 `UNKNOWN`；结构可读取的旧校准为 `NEEDS_REVIEW`，不会自动作为有效曲线应用。自动迁移从不删除 SharedPreferences。
- 空旧库只初始化一次 12 条 `BUILT_IN` 样例。统一清空保留 `samplesInitialized=true`，不会在下次启动回填；“恢复样例”是显式、可重复且不复制的操作。
- `MigrationGate` 仅在 `Completed`、`AlreadyCompleted` 或 `SkippedByUser` 后组合 NavHost；失败提供重试与二次确认的空库起步。后者记录 `SKIPPED_BY_USER` 并保留旧 JSON。
- 类型化路由覆盖 Home/Trends/Report/Profile、History、MeasurementGraph（ImageSelect → Crop → FactorSelect → Result）及 CalibrationGraph。顶层返回遵循访问历史，Home 根页才交给系统退出。

## 5. ELISA 量化模型（关键算法）

### 5.1 信号度量
- **孔内色度信号 = `tealness = B − R`**（蓝绿染色越正，浓度越高）。
- 依据 `Rule/SKILL.md`：ELISA 孔内色板从透明灰 `#9B9790` 到深青 `#6F8685`，即 B 通道相对 R 通道偏高。
- `FeatureExtractor` 用矩形区（而非圆/峰值）取均值+标准差，规避脆弱的圆心检测。

### 5.2 标准曲线插补 `StandardCurve`
- 输入信号 `tealness`，输出浓度 `pg/mL`，**分段线性插值**（"插补"）于 `(concentration, signal)` 节点之间。
- **出厂节点（FACTORY_KNOTS）** 由 `Rule/` 资产（测试用例 + 样本 + 3 张剪贴板板）用 90 分位液体像素 tealness 拟合得出，仅为"照片色度序数估计"。
- 低于首节点信号 → 0；高于末节点 → 封顶（不外推）。
- **曲线可覆盖**：`setKnots(Calibration)` 由校准流程写入；`resetKnots()` 还原出厂。
- 上限 `maxConcentration`：TNF-α/IL-1β = 500，IL-6 = 1000（取自样本梯级顶点）。

### 5.3 OA 炎症指数 `OaIndex`
- 对各因子浓度按 `caps` 归一化到 0~1，按权重合成 AI（0~1）：
  - 权重：`TNF_ALPHA 0.40 / IL6 0.35 / IL1_BETA 0.25`（TNF 优先）。
- 分级（设计规格，见 `Rule/界面.png`）：

  | 等级 | 区间 | 含义 |
  |---|---|---|
  | 0 | [0.00,0.25) | No risk / 极低活动 |
  | 1 | [0.25,0.50) | Mild |
  | 2 | [0.50,0.75) | Moderate |
  | 3 | [0.75,0.90) | Severe |
  | 4 | [0.90,1.00] | Very severe |

- 附带 `wellColor(intensity)`（色板映射）、`aiSeries`（时序）、`suggestions(grade, 周环比)`（报告建议）。
- **`caps` 已从占位值 6/8/4 修正为 500/1000/500**，避免真实数据在 grade 4 饱和。

### 5.4 已旁路的占位模型 `PredictionModel`
- Lasso 选出的 6 特征线性模型，**系数是占位值**。当前 `analyze()` 实际走 `StandardCurve`，未调用它；保留作说明/未来 `.tflite` 替换入口。

## 6. 校准体系（基线实现，Phase 2 待加固）

- 入口：Profile → **Calibrate Standard Curve**。
- 5 步流程 `CalibrationFlowScreen`：SELECT → CROP → ASSIGN（选因子、预填出厂梯级浓度）→ REVIEW（自动空白扣除：减去 conc=0 的 Blank 孔信号）→ DONE（保存）。
- `CalibrationDetector.detectGridSignals()`：把裁剪板按 3×3 网格切分，测每孔中心液体区 tealness。
- 校准持久化通过 `CalibrationRepository` → Room；只读旧 SP 由迁移协调器处理。
- Phase 1 迁移将旧曲线标为 `NEEDS_REVIEW`，不把未按 Phase 2 科学规则重新验证的曲线激活。

- Room 样例提供器使用稳定 ID 填充 **12 个 `BUILT_IN` TestSession**：

## 11. 关键设计决策记录（Decision Log 摘要）

| 决策 | 选择 | 理由 |
|---|---|---|
| 浓度来源 | 照片 tealness 插补 | 无酶标仪，SKILL.md 仅含色板 |
| 信号度量 | B − R（tealness） | 蓝绿染色随浓度升高 |

| caps | 500/1000/500 | 样本梯级上界，防饱和 |

### 12.2 已实现的导航与返回

- 顶部返回、系统返回和预测性返回使用同一 NavController 返回栈。
- 检测前三步与校准各步骤逐级返回。
- 检测 Result 是已提交终点，返回发起检测前的页面，避免重复写入。
- 顶层页面按访问历史返回，最后回到 Home；只有 Home 根页面再次返回才退出。
- 图片使用 URI，草稿用 `SavedStateHandle` 保存，支持旋转和语言切换恢复。

### 12.3 已实现的 Room 与数据策略

- Room v1 表结构：

  | 表 | 主键/关系 | 核心字段 |
  |---|---|---|
  | `test_session` | `id` | `name`, `createdAt`, `source: USER/BUILT_IN` |
  | `test_result` | `id`; `sessionId` 外键级联 | `factor`, `concentration`, timestamp, 6 个 RGB 特征, `rangeStatus`, nullable unique `draftId` |
  | `calibration` | `factor` | `createdAt`, `version`, `status: ACTIVE/NEEDS_REVIEW` |
  | `calibration_knot` | `factor + position`; 外键级联 | concentration, raw/fitted signal, `isBlank` |
  | `app_metadata` | key | legacy migration、样例初始化和审计标记 |

- 旧检测与校准 JSON 在单一事务中完整验证和导入，成功前不写迁移标记；旧 SP 暂留为只读回退。
- 旧结果缺少范围信息时迁移为 `UNKNOWN`；旧校准不符合新规则时保留为 `NEEDS_REVIEW`，但不应用到新检测。
- 迁移失败显示恢复界面，不写样例；用户二次确认放弃迁移时记录 `SKIPPED_BY_USER` 和 `samplesInitialized=true`，旧 JSON 仍不删除。
- 内置 12 板标记为 `BUILT_IN`，只首次安装初始化。
- “清空全部数据”统一删除用户检测、样例和用户校准，但保留已初始化标记，重启不回填。
- 个人中心提供显式“恢复样例数据”，只恢复样例，不恢复校准。

### 12.4 多语言：基础设施完成，屏幕资源化待 Phase 3
