阶段 1 · Room 数据模型与无损迁移

Room 成为唯一运行时数据源；旧 SharedPreferences 仅作为一次性迁移输入保留，不再承担写入。

数据库 v1

test_session

  • id · 主键
  • name / createdAt
  • source: USER | BUILT_IN

test_result

  • id · 主键
  • sessionId · 外键级联
  • factor / concentration
  • RGB 均值与标准差

calibration

  • factor · 主键
  • createdAt / version
  • kit metadata

calibration_knot

  • factor + position
  • concentration
  • signal / isBlank

app_metadata

  • legacyMigrationStatus
  • samplesInitialized
  • schema 与审计标记
Session 1 → N Result · Calibration 1 → N Knot
首次启动协调器
1
检查迁移标记已完成则直接订阅 Room Flow。
2
解析旧 JSON会话、结果与校准全部验证后再写入。
3
单事务导入任一记录失败即整体回滚，不产生半迁移状态。
4
一次性样例初始化没有旧会话时写入 12 板 BUILT_IN 数据。
5
保留旧源成功后写入标记，但不删除旧 SP，便于版本回退与核验。
统一清空检测、样例、校准在单一事务内全部删除。
不自动回填清空后保持空态，重启不会恢复 12 板。
手动恢复样例独立操作只恢复 BUILT_IN 数据，不恢复校准。
